In order for this application to run correctly it is recommended to install following versions of Java Development Kit and JavaFX SDK:
-Java SE Development Kit 17.0.8 - https://www.oracle.com/java/technologies/javase/jdk17-archive-downloads.html
-JavaFX SDK 21.0.1 - https://gluonhq.com/products/javafx/
JavaFX SDK requires additional configuration upon installation. For more information refer to the guide on the official JavaFX website: https://openjfx.io/openjfx-docs/
